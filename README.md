# Raiju Linux

## **Status:** Work in Progress

Raiju Linux is a personal Linux distribution currently under development.  
It is based on Arch Linux and aims to provide a customized, lightweight, and user-friendly experience.  

The goal is to create a distro featuring:  
- XFCE + Openbox desktop environment  
- Pre-installed tools for developers and sysadmins  
- Easy-to-use installer (based on Manjaro's Calamares)  
- Custom configurations, themes, and scripts  

Stay tuned for updates as the project progresses!
